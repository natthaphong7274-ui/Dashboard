แดชบอร์ดนี้ออกแบบมาเพื่อช่วยให้คุณติดตามผลงานระดับทีมและรายบุคคลได้อย่างรวดเร็ว

💡 คำศัพท์ที่พบบ่อย

  • Rev (Revenue): รายได้รวม หรือยอดเงิน
  • Vol (Volume): จำนวนออเดอร์ หรือปริมาณงาน
  • Target / เป้า: สามารถกำหนดเป้าหมายเพื่อใช้วัด Performance (เฉพาะ Director/AM)
  • Threshold (เฝ้าระวัง): เกณฑ์ % ที่ถ้าทำได้ต่ำกว่าจะถูกจัดอยู่ในกลุ่มเสี่ยง

⌨️ Keyboard Shortcuts (ปุ่มลัด)

ทำงานได้เร็วขึ้นโดยไม่ต้องใช้เมาส์:

  • กด 1 ถึง 5 เพื่อสลับหน้าเมนูหลัก
  • กด Ctrl + K เพื่อค้นหา Agent / BD อย่างรวดเร็ว
  • กด Esc เพื่อปิดหน้าต่างหรือยกเลิกการพิมพ์
