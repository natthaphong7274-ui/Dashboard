# UX Sprint 5: Reusable Empty & Error States

**สถานะ:** ทำแล้ว, รอทดสอบ
**Branch:** `UX_Sprint-5`

## สรุป
ออกแบบและพัฒนาระบบสถานะ "ไม่มีข้อมูล" (Empty State) แบบรวมศูนย์ เพื่อให้กราฟ ตาราง และหน้าต่างเจาะลึกทั้งหมดใน Dashboard แสดงผลไปในทิศทางเดียวกัน โดยยึดหลักการความเร็ว (Lean) และความโปร่งใส (Clear Context) ทำให้ผู้ใช้ไม่ต้องคาดเดาว่าหน้าจอค้าง หรือมีปัญหาข้อมูล

## สิ่งที่ปรับปรุง (Changelog)

### 1. ระบบ CSS กลาง (Centralized Empty State CSS)
- สร้างคลาส `.empty-panel` สำหรับคลุมพื้นที่ที่ว่างเปล่า (จัดให้อยู่ตรงกลางเสมอทั้งแนวตั้งและแนวนอน)
- รองรับหลายอารมณ์ (Contexts):
  - **Neutral State:** ข้อความสีเทา (เช่น "กำลังรอข้อมูล")
  - **Positive State (`.positive`):** ไอคอนโล่สีเขียว และข้อความสีเขียว
  - **Warning State (`.warning`):** ไอคอนเตือน และข้อความสีส้ม

### 2. JavaScript Helper Functions
- `setEmpty(canvasId, type, msg)`: ฟังก์ชันสำหรับซ่อน Canvas ชั่วคราว แล้วแสดงกล่อง Empty State ขึ้นมาแทนที่โดยอัตโนมัติ ไม่ทำลาย Element กราฟ
- `clearEmpty(canvasId)`: ฟังก์ชันกู้คืน Canvas เดิมกลับมาเมื่อข้อมูลพร้อมแล้ว 
- ผูก `clearEmpty` เข้ากับฟังก์ชันสร้างกราฟหลักทั้งหมด (`mkLine`, `mkBar`, `mkHBar`, `mkDonut`) ทำให้แทบไม่ต้องเขียนโค้ดเคลียร์สถานะเองอีก

### 3. Smart Ranking Empty State
- ปรับตาราง Ranking (`mkRank`) ให้แสดง **โล่สีเขียว (Positive State)** ทันทีที่การสืบค้นข้อมูลเป็น 0 เช่น การหาผู้ติดลบแต่ไม่พบ ซึ่งสื่อถึง "สถานการณ์ปกติ" ช่วยลดความกังวลของผู้ใช้ (No news is good news)

## ไฟล์ที่ถูกแก้ไข

## Checklist สำหรับตรวจสอบ (QA)
- [ ] เมื่อกด Filter ข้อมูลจนไม่มีกราฟขึ้น จะต้องเห็นข้อความบอกชัดเจนว่า "ไม่มีข้อมูล" แทนที่จะเป็นพื้นที่ขาวๆ หรือ Layout พัง
- [ ] หากตารางจัดอันดับ (Ranking) ว่างเปล่า จะต้องขึ้นไอคอนโล่สีเขียว พร้อมข้อความ "ไม่มีรายชื่อในกลุ่มนี้"
- [ ] ลองสลับข้อมูลไปมา (เช่น เอา Filter ออก) กราฟที่เคยถูกซ่อนด้วย Empty State จะต้องกลับมาแสดงได้อย่างถูกต้อง ไม่โดนทับ
